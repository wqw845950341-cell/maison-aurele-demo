# Maison Aurèle · AI Clienteling Demo

[打开在线 Demo](https://wqw845950341-cell.github.io/maison-aurele-demo/)

以虚构奢华护肤品牌 Maison Aurèle 为场景的移动端 H5 原型，视觉参考奢侈品牌数字精品店与微信小程序。

## 使用流程

- **接待速览**：切换王女士与未留名男士，查看身份、上次沟通、承诺与本次注意事项；随时核对原始口述。
- **语音复盘**：顾客离店后主动点击麦克风，最长录音 60 秒。结束可回听，浏览器支持时同步中文转写；可手动校对、补录，或载入明确标注的题目示例。
- **校对入档**：检查整理预览中的人物、产品、数量、承诺与时间，人工确认后存入当前顾客的客户记忆。
- **跟进关照**：编辑示例草稿、人工审阅，再复制文案由顾问自行发送。编辑后需重新审阅。

## 演示能力

录音与回听使用浏览器 MediaRecorder；中文转写依赖可用的 SpeechRecognition 服务。浏览器和网络条件会影响支持情况。录音仅供当前页面回听；本站没有音频上传或持久存储接口。浏览器语音服务自身可能联网处理音频，使用前请留意页面说明。

整理为规则与预置案例演示，跟进文案为预置示例，未连接真实大模型、CRM、POS、库存、自动提醒或消息发送。

人工确认的文本、补充记录、草稿和阅读状态仅保存在本浏览器。案例人物与品牌来自题目中的虚构场景，不包含真实客户数据。

## 部署与更新

纯 HTML / CSS / JavaScript，无依赖、无需构建。GitHub Pages 从发布分支的根目录部署。提交更新后会重新发布。

本地可用任意静态 HTTP 服务打开根目录。录音需要 HTTPS 或 localhost，以及用户主动授权麦克风。
